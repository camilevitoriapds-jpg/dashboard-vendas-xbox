# Dashboard de Vendas — Xbox Game Pass

## Sobre o projeto

Este projeto apresenta um dashboard de vendas desenvolvido no Excel com foco na organização, análise e visualização de dados de assinaturas do Xbox Game Pass.

O objetivo é transformar os dados brutos de assinantes em informações visuais que facilitem a análise do desempenho das vendas e apoiem a tomada de decisões baseada em dados.

## Dados utilizados

A base contém informações de assinantes, incluindo:

- ID e nome do assinante;
- plano contratado;
- data de início;
- renovação automática;
- preço da assinatura;
- tipo de assinatura;
- contratação do EA Play Season Pass;
- contratação do Minecraft Season Pass;
- valores dos complementos;
- valor de cupom;
- valor total da venda.

## Estrutura do arquivo Excel

O arquivo `dashboard_xbox_finalizado.xlsx` está organizado nas seguintes abas:

- **Assets:** elementos visuais e paleta de cores utilizados no dashboard;
- **Bases:** base de dados dos assinantes;
- **Cálculos:** análises e respostas às perguntas de negócio;
- **Dashboard:** painel visual consolidando os principais resultados.

## Análises realizadas

Entre as análises apresentadas estão:

1. Faturamento total das vendas de planos de assinatura;
2. Faturamento separado por renovação automática;
3. Total de vendas do EA Play Season Pass;
4. Total de vendas do Minecraft Season Pass.

## Como reproduzir

1. Abra o arquivo `dashboard_xbox_finalizado.xlsx` no Microsoft Excel.
2. Consulte a aba **Bases** para visualizar os dados utilizados.
3. Consulte a aba **Cálculos** para acompanhar as análises.
4. Acesse a aba **Dashboard** para visualizar o painel final.
5. Caso a base seja alterada, atualize as tabelas dinâmicas/elementos de análise no Excel para refletir os novos dados.
